# Jianing (Bruce) Fan

Personal website for AI engineering, research, and writing.

Published at https://brucefjn.github.io/.

## Structure

- `index.html`: portfolio content and page metadata
- `styles.css` and `script.js`: presentation and interactions
- `assets/`: photographs, research figures, fonts, and downloadable documents
- `image-credits.html`: compatibility redirect for previously shared links
- `robots.txt` and `sitemap.xml`: search discovery

This is a static website. GitHub Pages publishes the root of the `main` branch; no build step is required.

## Content and credits

Paper bylines and academic credits use Jianing Fan. Third-party photographs and research materials are credited in their captions with direct source and license links. Fonts retain the license files accompanying their assets. There is no separate credits page or footer link.

If the website moves to a custom domain, update the canonical URL, social-image URLs, structured profile metadata, robots sitemap address, and sitemap together.
